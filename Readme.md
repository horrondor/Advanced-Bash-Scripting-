# 📘 Advanced Bash Scripting Learning Repository

This repository documents my learning journey through the **Advanced Bash-Scripting Guide (ABS)** from TLDP.

🔗 Official Guide: https://tldp.org/LDP/abs/html/

---

## 🚀 About the Guide

The Advanced Bash-Scripting Guide is a comprehensive resource that starts from basics and gradually moves toward advanced shell scripting concepts, including real-world examples and exercises. It is designed as a **self-study manual, reference, and hands-on practice resource**. ([The Linux Documentation Project][1])

---

## 🎯 Learning Goals

* Understand Bash fundamentals
* Write efficient shell scripts
* Automate system tasks
* Learn debugging and best practices
* Build real-world scripting projects

---

## 📚 Topics Covered

### 🟢 Basics

* Shebang (`#!/bin/bash`)
* Variables & parameters
* Quoting & escaping
* Exit status and tests

### 🟡 Intermediate

* Loops & conditionals
* Functions
* Command substitution
* Arithmetic operations

### 🔴 Advanced

* Arrays and indirect references
* Regular expressions
* I/O redirection
* Subshells & process substitution
* Debugging techniques

## 🛠️ How to Use

1. Clone this repository:

```bash
git clone https://github.com/yourusername/bash-learning.git
cd bash-learning
```

2. Run scripts:

```bash
chmod +x script.sh
./script.sh
```
